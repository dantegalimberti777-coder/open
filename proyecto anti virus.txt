================================================================================
 RESUMEN EN UNA LINEA
================================================================================
Tenemos un antivirus funcional (motor + interfaz grafica + .exe de Windows) con
escaneo rapido/profundo, barra de progreso, cuarentena, actualizaciones y un
sistema de cobro (14 dias gratis, luego 10 USD/mes). Todo probado y guardado en
Git.


================================================================================
 COMO SE USA (lo que tenes hoy)
================================================================================
1) Descomprimir el archivo NGAV-Windows.zip.
2) Doble clic en "Iniciar NGAV.bat" -> abre la interfaz en el navegador.
3) En la interfaz:
   - Panel: estado y puntuacion de proteccion.
   - Escaner: Escaneo RAPIDO o PROFUNDO, con barra de progreso en %.
   - Cuarentena: ver/restaurar/eliminar amenazas aisladas.
   - Herramientas: "Buscar actualizaciones" de firmas.
   - Suscripcion: 14 dias gratis, luego 10 USD/mes; activar clave.
   - Ajustes y modo oscuro.

Por linea de comandos (opcional):
   NGAV.exe selftest              -> prueba el motor con el archivo EICAR
   NGAV.exe scan C:\ruta          -> escanea una carpeta
   NGAV.exe scan C:\ruta --quarantine  -> escanea y pone en cuarentena
   NGAV.exe serve                 -> abre la interfaz grafica
   NGAV.exe status                -> estado del agente


================================================================================
 TECNOLOGIAS USADAS
================================================================================
- Motor y agente:      Rust (sin dependencias externas -> compila y es seguro)

- Servicios en nube:   Go (reputacion y licencias/facturacion)
- Ejecutable Windows:  compilado desde Linux (cross-compilacion con MinGW)
- Control de versiones: Git

ETAPA 2 - MOTOR DE DETECCION (codigo real en Rust)
--------------------------------------------------------------------------------
Se programo el nucleo del antivirus (carpeta endpoint/agent-core/), todo
probado con tests automaticos. Piezas:
  - hash.rs ........ Calcula SHA-256 (huella unica de cada archivo).
  - entropy.rs ..... Mide "entropia" (detecta archivos cifrados/empaquetados).
  - signatures.rs .. Firmas: compara contra una base de amenazas conocidas.
  - heuristics.rs .. Reglas que detectan comportamiento sospechoso.
  - reputation.rs .. Reputacion: consulta si un archivo es conocido bueno/malo.
  - decision.rs .... Motor de decision: junta todas las senales y decide
                     LIMPIO / SOSPECHOSO / MALICIOSO.
  - engine.rs ...... Orquesta todo lo anterior por cada archivo.
  - scanner.rs ..... Recorre carpetas; escaneo incremental (salta lo ya visto).
  - quarantine.rs .. Aisla archivos maliciosos (los guarda cifrados/ofuscados).
  - config.rs ...... Configuracion y rutas.
  - main.rs ........ Comandos de consola (scan, selftest, status, etc.).
Verificado: detecta el archivo de prueba estandar EICAR como MALICIOSO.

--------------------------------------------------------------------------------
ETAPA 3 - SERVICIO EN LA NUBE (reputacion)
--------------------------------------------------------------------------------
Se creo cloud/reputation/ (en Go): responde si un archivo (por su huella) es
bueno, malo o desconocido. Incluye defensa: reportar algo muchas veces NO lo
convierte en "bueno" (evita que enganien al sistema).

--------------------------------------------------------------------------------
ETAPA 4 - INTERFAZ GRAFICA (programa con ventana/pantalla)
--------------------------------------------------------------------------------
Se creo una interfaz limpia con barra de opciones a la izquierda (estilo
Malwarebytes): Panel, Escaner, Detecciones, Cuarentena, Herramientas, Ajustes.
Incluye medidor de "puntuacion de proteccion" y MODO OSCURO.
El propio agente incluye un mini servidor web que muestra la interfaz en el
navegador con el comando: NGAV.exe serve

--------------------------------------------------------------------------------
ETAPA 5 - EJECUTABLE .EXE DE WINDOWS
--------------------------------------------------------------------------------
Se genero un NGAV.exe real para Windows (64 bits), autocontenido (la interfaz va
dentro del programa). Se armo el paquete NGAV-Windows.zip con:
  - NGAV.exe
  - signatures.db (base de firmas)
  - "Iniciar NGAV.bat" (para abrir con doble clic)
  - LEEME.txt (instrucciones)
Script para reconstruirlo: infra/ci/build-windows.sh

--------------------------------------------------------------------------------
ETAPA 6 - ESCANEO RAPIDO/PROFUNDO + BARRA DE PROGRESO + ACTUALIZACIONES
--------------------------------------------------------------------------------
Se agrego:
  - Escaneo RAPIDO: zonas de riesgo (temporales, descargas, autoarranque) mas
    los procesos en ejecucion (la "CPU").
  - Escaneo PROFUNDO: todo el sistema/disco + procesos.
  - BARRA DE PROGRESO con porcentaje en tiempo real (medidor circular + barra +
    archivo actual + contadores de amenazas).
  - Mas deteccion: troyanos, RAT/C2, rootkits, keyloggers, mineros, gusanos,
    robo de credenciales (Mimikatz/LSASS), evasion de Defender/AMSI, LOLBins.
  - AUTO-ACTUALIZACION de firmas desde la nube (boton "Buscar actualizaciones" y
    auto-chequeo al arrancar). El servicio Go entrega las firmas nuevas.
  - Proteccion: salta archivos gigantes (>128 MB) para no trabarse.

--------------------------------------------------------------------------------
ETAPA 8 - ANALISIS PROFESIONAL + PROTECCION EN TIEMPO REAL (evolucion NGAV)
--------------------------------------------------------------------------------
Primero se AUDITO todo el proyecto (sin tocar codigo) y se diseno la arquitectura
de evolucion a NGAV/XDR profesional:
  - docs/evolucion/00-analisis-arquitectura.md: fortalezas, debilidades, cuellos
    de botella, riesgos (seguridad/rendimiento/escalabilidad), arquitectura
    objetivo (Clean Architecture + Ports & Adapters) y plan por etapas.
Luego se implemento la primera etapa (con tests y documentacion):
  - PROTECCION EN TIEMPO REAL (src/realtime.rs): vigila creacion/modificacion/
    renombrado de archivos en las zonas de riesgo y los analiza APENAS aparecen,
    sin escaneos manuales. Pone en cuarentena lo malicioso automaticamente.
    Usa notificaciones del kernel (inotify/ReadDirectoryChangesW/FSEvents) -> CPU
    casi cero en reposo. Interruptor real en la interfaz + linea temporal de
    amenazas en "Detecciones".
  - SEGURIDAD: la API local ahora rechaza peticiones de origen no local
    (bloquea CSRF/DNS-rebinding desde el navegador) y limita el tamaño de las
    peticiones (anti-DoS). Se corrigio un falso positivo de la firma EICAR.
  - Se autorizo usar dependencias curadas (primera: notify) con Cargo.lock fijado.
  - Documentado en docs/evolucion/01-tiempo-real.md. 50 tests en verde.

--------------------------------------------------------------------------------
ETAPA 7 - MONETIZACION (COBRO): 14 DIAS GRATIS, LUEGO 10 USD/MES
--------------------------------------------------------------------------------
Se agrego el sistema de licencias y cobro:
  - El agente lleva la cuenta de los 14 dias de prueba (archivo license.txt).
  - Banner arriba: "Prueba - N dias" + boton "Comprar ahora".
  - Pantalla "Suscripcion" con el precio 10 USD/mes, lista de beneficios y
    campo para activar la clave de licencia.
  - Al terminar la prueba SIN pagar, los escaneos se BLOQUEAN hasta suscribirse.
  - Servicio de facturacion cloud/licensing/ (Go), listo para Stripe:
      * MODO DEMO (por defecto): entrega una clave sin cobro real, para probar.
      * MODO STRIPE (cobro real): con STRIPE_SECRET_KEY y STRIPE_PRICE_ID crea el
        pago real de 10 USD/mes con 14 dias de prueba.
  - Documentado en docs/monetizacion.md (incluye pasos para conectar Stripe).
Verificado de punta a punta: prueba activa -> escaneo OK; prueba vencida ->
escaneo bloqueado; pago (demo) -> clave -> activada -> escaneo OK de nuevo.
